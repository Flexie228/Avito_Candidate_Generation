Для запуска:

Скачайте папку с весами модели по ссылке [https://drive.google.com/drive/folders/16b72uztMvQP_OzN47lMIJ5OjkXz3cF1E?usp=sharing]  и положите ее в корень проекта.
Файлы (benchmark_items.parquet и benchmark_queries.parquet) поместите в папку data/.

Программу можно запускать. Важный момент: при первом запуске программа будет отрабатывать дольше, чем при последующих, это связано с генерацией словарей, которые программа один раз создаст локально, а дальше будет их использовать.
Предлагаю вам сразу скачать эти 2 файла и положить их в папку data/.
